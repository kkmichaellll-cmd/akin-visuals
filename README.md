- The two thesis cover designs have been preserved.
- For web publication, source JPEG artwork is resized/compressed, without redesigning its contents. Native CMYK/AI/PSD files are not appropriate as browser image assets.
- The existing website's publication entries, statistics and testimonial placeholders have NOT been independently verified; confirm these before presenting them as client facts.

- This package does not alter the existing live deployment.
